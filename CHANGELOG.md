# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-06-03

### Added
- **Share / Copy-Link button** in MatchDetail view — share individual match URLs to clipboard or native share sheet
- **Team form guide** in league table — last 5 results shown as coloured W/D/L badges per team
- **Winning team highlight** and **score margin** displayed on completed match cards in fixtures
- **AGENTS.md** — project conventions and testing patterns for AI coding agents and contributors

### Changed
- Upgraded from initial scaffold (`0.0.0`) to first numbered release

### Notes
- Many additional features are in open draft PRs awaiting maintainer review (dark mode, skeleton loading, PWA support, URL deep-linking, sortable standings, and more)
